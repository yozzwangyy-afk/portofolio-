Riyo

Saya Riyo, developer dari Indonesia. Hampir semua yang saya buat berupa website: tampilannya, server di belakangnya, sambungan ke API, database, sampai sistem login.

Selain itu saya suka membuat chatbot AI dan bot WhatsApp, dan hampir selalu ada satu proyek yang sedang saya kerjakan.

01

Yang saya kerjakan

Website
Ditulis dengan HTML, CSS, dan JavaScript. Dari halaman biasa sampai aplikasi yang punya akun pengguna.
Tampilan (frontend)
Halaman yang enak dibuka di HP maupun laptop, dan mudah dipahami orang yang baru pertama kali masuk.
Server (backend)
Mengolah data, membuat endpoint API, mengurus login, dan menjalankan logika di sisi server.
Sambungan API
Menghubungkan website ke layanan lain, misalnya API anime dan API AI.
Database
Firebase dan Firestore untuk menyimpan data aplikasi dan pengguna.
AI
Memasang AI ke dalam chatbot dan aplikasi.
Bot WhatsApp
Bot yang bisa menjawab lewat AI, punya fitur moderasi, dan ada permainan di dalamnya.

04

Cara saya belajar

Menjadi developer itu tidak berhenti di menulis kode. Waktunya banyak habis untuk memahami cara kerja sebuah sistem, membaca dokumentasi, dan mencari tahu kenapa sebuah error muncul.

Cara belajar saya: membuat proyek yang sungguhan, lalu mencari tahu bagian yang belum paham saat tersangkut di tengah jalan.

05

Di luar kode

Saya suka anime dan video editing, dan senang mencoba teknologi baru. Ketiganya sering jadi bahan untuk proyek berikutnya, jadi tidak terpisah dari kerjaan saya.

06

Yang ingin saya capai

Saya ingin makin kuat di full-stack: membuat proyek yang lebih rapi, berjalan dengan benar, dan aman dipakai orang lain.

Setiap proyek saya anggap latihan untuk proyek berikutnya.
